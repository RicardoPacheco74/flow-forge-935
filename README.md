# AI Agents Unleashed

Quero que você desenvolva uma Landing Page Premium para vender meu curso "Automação e Criação de Agentes de IA com n8n".

NÃO quero uma landing page comum.

Quero uma página extremamente moderna, cinematográfica e altamente persuasiva, pensada para servir também como roteiro visual de uma VSL.

Enquanto gravo meu vídeo de vendas, navegarei pela página abrindo cada seção. Portanto, praticamente todo o conteúdo principal deverá estar organizado em Accordions elegantes e animados.

====================================================

REFERÊNCIA DE DESIGN

====================================================

Utilize como inspiração o Design System anexado.

Não copie o layout.

Utilize apenas a linguagem visual.

Gosto principalmente de:

• fundo escuro

• muito contraste

• glassmorphism

• glow

• bordas suaves

• gradientes

• blur

• animações suaves

• cards premium

• efeitos luminosos

• componentes sofisticados

• bastante espaço em branco

• aparência tecnológica

Porém adapte a paleta para algo próximo da identidade do n8n.

Utilize principalmente:

verde n8n

tons de cinza

preto

grafite

verde neon para destaques

Evite utilizar o laranja predominante do Design System.

Quero que qualquer pessoa olhe para a página e pense imediatamente em IA, Automação, Workflow e Tecnologia.

====================================================

OBJETIVO

====================================================

A página deve passar a impressão de um produto Premium.

Ela deve prender a atenção durante toda a navegação.

Cada seção deve possuir pequenas animações de entrada.

Hover effects.

Elementos com movimento discreto.

Scroll suave.

Background com partículas.

Linhas de conexão.
